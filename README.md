## Project Contents for CIND 820
The aim of this project is to develop machine learning models that accurately predict the presence of diabetes given a set of 21 features based on health and lifestyle traits. The project incorporates Support Vector Classifiers, LinearSVC, K-Nearest Neighbours, and Stochastic Gradient Descent Classifiers to predict results.  
\
**Final contents can be found within 'final code and results' folder.**
