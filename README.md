Repository contains project contents for CIND 820. The aim of this project is to develop machine learning models that accurately predict the presence of diabetes given a set of 22 features based on health and lifestyle traits. The project incorporates Support Vector Classifiers, LinearSVC, K-Nearest Neighbours, and Stochastic Gradient Descent Classifiers to predict results.
Analysis code can be found within DiabetesProject under diabetestests.py.
Result output can be found under results.pdf.
Dataset can be found under diabetes_binary_health_indicators_BRFSS2015.csv.
Figures are uploaded depicting model performance metrics.
